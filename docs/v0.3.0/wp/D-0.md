## Decisions

- **Names kept, values changed.** `canvas`, `panel`, `sunken`, `hover`, `sidebar`, `ink`, `dim`,
  `line`, `line-strong`, `accent`, `accent-soft`, `accent-fill(-ink/-edge)`, the feedback,
  status, token and provenance names keep their meaning, so features restyled untouched. The
  primary button got its own `primary` tokens rather than reusing `accent-fill`: green is not the
  accent (selection and working are blue).
- **Dark surfaces as GitHub's:** `canvas` = `panel` `#0d1117`, `subtle` = `panel-raised`
  `#151b23`, `sunken` the inset `#010409` (board columns sit below the cards). `sidebar` is
  `#f6f8fa` / `#010409`.
- **Translucent dark fills** (`#2ea04326`, `#bb800926`, `#f8514926`, `#388bfd1a`, `#ab7df826`)
  are stored blended over the dark canvas as opaque tokens, so the contrast test measures them;
  the diff keeps GitHub's translucent values and the diff test blends them as painted.
- **One deviation from GitHub's values:** the dark `danger` is `#fa5b53`, not `#f85149`, which is
  4.4:1 on the default (grey) button where the danger button shows its red text.
- **Dark primary hover** is `#207c33` (darker than GitHub's `#29903b`, which is 4.0:1 with white).
- **Shiki syntax colors:** GitHub's prettylights where they pass; keyword, function, constant,
  comment and parameter a step darker (light) or lighter (dark) where they fell under 4.5:1 on a
  changed-word tint.
- **The sidebar toggle's names** follow the owner's tooltip words: "Hide sidebar" / "Show
  sidebar" (they were "Collapse sidebar" / "Expand sidebar"), so the visible tooltip and the
  accessible name agree; the test id `sidebar-toggle`, `aria-keyshortcuts` and the remembered
  choice are unchanged. It also has `aria-controls="app-sidebar"` and `aria-expanded`. It sits in
  the top bar's first cell, as wide as the rail, so it is over the sidebar column and stays in
  place over the icon rail; the brand cell no longer matches the sidebar's width.
- **Settings → Appearance** is a card on the project's Settings page (the app has no global
  settings page); its text says it is for this browser.
- **New copy** (only what the owner asked for): `SHELL_COPY.nav.workspace` ("Workspace"), the
  theme menu's words (`SHELL_COPY.theme`: "Theme", "Light", "Dark", "System", "Follows your
  computer", "Appearance", "How the app looks in this browser."), the toggle's two names.
- **Cards with `padded={false}`** now begin right under the header's divider; five features that
  drew their own top border or gap for the old header (live workflow, run graph, Workflow page
  palette, changes overview, cost and token breakdown cards) lost it, so there is no double line.
- **Tabs keep one weight** (medium) when selected, so they never shift; the selection is the
  `ink` color and the accent bar.
- **No toast exists** in the app (saved forms say so in place), so there was none to restyle.
- **Fonts:** only the import and `fonts.css` are gone; `@fontsource-variable/inter` and
  `@fontsource-variable/jetbrains-mono` are still dependencies (package.json untouched, as told).
