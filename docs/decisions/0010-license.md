# ADR-0010: MIT license

- **Status:** accepted — confirmed by the project owner on 2026-10-10 (was provisional)
- **Date:** 2026-10-10

## Context

The project is intended to be open source. A license file is needed so contributions have clear terms.

## Decision

MIT, copyright "Agent Control Plane contributors".

## Alternatives considered

- Apache-2.0: includes an explicit patent grant. It is a reasonable choice for infrastructure tooling.
  Switch to it if the owners prefer that grant.

## Consequences

Changing the license after outside contributions requires contributor consent. Decide before
accepting external PRs.
