# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. In short:

- Be respectful and constructive. Assume good faith.
- No harassment, discrimination, personal attacks, or publishing others' private information.
- Focus criticism on ideas and code, not people.

These standards apply in all project spaces: issues, pull requests, discussions, and any community
channels. They also apply when someone represents the project elsewhere.

## Enforcement

Report unacceptable behavior to the maintainers privately (see [SECURITY.md](SECURITY.md) for the
contact channel until a dedicated conduct address exists). Maintainers will review reports promptly
and confidentially, and may take any action they judge appropriate, up to a permanent ban, as
described in the Contributor Covenant's enforcement guidelines.
